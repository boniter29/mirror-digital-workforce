# 林氏·镜我｜企业数字员工生成与运营平台

将专家经验沉淀为可持续迭代的岗位能力。

镜我是一款本地 Electron 应用：通过访谈、工作资料与授权范围内的钉钉证据，生成数字分身；通过对话测试、纠错与版本管理改进表现；再将已发布版本绑定到钉钉机器人和指定群聊。

本仓库是参赛用途的脱敏代码快照，基于镜我 0.8.0。只包含应用代码、构建脚本及通用测试，不包含原仓库提交历史、业务聊天、人员档案、运行日志、真实评测答案、模型密钥或机器人凭据。

## 核心能力

- **经验采集与蒸馏**：HR 访谈、DWS 证据采集、人格蒸馏三种工作角色，共用一个 Agent 运行底座，按需加载 Skills。
- **语气与知识承载**：将身份、表达、判断、知识、边界与记忆分开组织，保留来源归属。
- **纠错与版本管理**：独立版本分支、测试会话、反馈、发布快照与机器人路由。
- **业务入口**：钉钉 Stream / Webhook 接入，机器人、群聊与分身版本分别绑定。
- **本地知识与视觉**：文件导入、知识工作区、OCR 及模型原生视觉能力。
- **模型适配**：支持 Anthropic，以及 GLM、DeepSeek、OpenRouter、Kimi 和兼容 Anthropic Messages 的自定义端点；能力取决于实际配置的服务。

## 已应用的业务方向

项目负责人确认已在生产使用的场景包括：线上营销数字化运维、内部 AI 工具运维群、AI 产品创新部门内部管理问答，以及行政考勤的一对一答疑。公开仓库不包含这些场景中的私有数据和访问凭据。

## 技术组成

| 层次 | 实现 |
| --- | --- |
| 开发工具 | TRAE |

| Agent 运行底座 | Claude Agent SDK；单 Agent 按需调用工具和 Skills |
| 模型服务 | 可配置模型供应商，本地应用通过 API 调用 |

## 本地运行

需要 Node.js 22.5 或更新版本，以及用户自行配置的模型服务凭据。钉钉功能需要有效的 DWS 身份和自有企业应用/机器人配置。

```sh
npm ci
npm run dev
```

开发启动后，在应用设置中填写自己的模型服务信息。钉钉接入请使用自己的测试机器人和测试群，先验证收发与路由，再用于实际业务。真实模型调用会产生供应商账单。

```sh
npm run typecheck
npm test
npm run build
```

Windows 安装包可在本地构建：`npm run package:win`。构建脚本会准备 DWS 和 OCR 依赖；这些二进制依赖不包含在本仓库。

`npm run dev:web` 只用于查看界面原型，其 mock 数据为合成示例，不能替代 Electron 中的真实 Agent、DWS 和机器人链路。

## 隐私与授权

请勿提交 API Key、Client Secret、Webhook Token、真实员工考勤或聊天数据。模型凭据由应用的本地凭据管理机制保存；仅将确有授权的资料用于构建分身。

本仓库未授予额外的开源许可。第三方组件按各自许可证使用；DWS 的许可证及声明保留在 `build-resources/dws/`。
